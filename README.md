# C3 Mosaic Present: releases

Installers for **C3 Mosaic Present**, the worship presentation app of C3 Mosaic Iglesia
Cristiana. This repository holds only the released installers and their notes; the app's code
is kept elsewhere.

## Installing

Open the **[latest release](https://github.com/C3Mosaic/present-releases/releases/latest)**
and download the file ending in **.exe** (`C3-Mosaic-Present-Setup-….exe`), then run it.

The installer isn't signed, so the first time Windows may say "Windows protected your PC":
choose **More info**, then **Run anyway**.

## Updates

Once installed, Present checks this page for a new version by itself (shortly after it starts,
and once a day, never during a service) and offers it: **Download**, then **Install and
restart**. Settings and content are kept.
